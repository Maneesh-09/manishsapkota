

# Personal Portfolio App

A modern, premium portfolio website with Deep Indigo + Teal theme, smooth animations, dark/light mode, and a working contact form.

## 1. Landing / Hero Section
- Bold name, title, and tagline with large typography (Poppins-style headings, Inter body)
- Abstract avatar placeholder
- CTA buttons: "View Projects" and "Contact Me"
- Subtle gradient background with glassmorphism accents
- Smooth fade-in animations on load

## 2. About Section
- Short bio (3-5 lines) with clearly marked placeholder text
- Icon-based core strengths highlights
- Mini experience timeline preview

## 3. Projects Section
- Card grid layout (responsive 1-2-3 columns)
- Each card: placeholder image, title, description, tech stack icons, "Live Demo" and "GitHub" buttons
- Cards with hover lift effect and subtle shadows
- Modal or expanded view on click for project details
- 4-6 placeholder projects

## 4. Skills Section
- Categorized: Frontend, Backend, Tools
- Clean dev icons using Lucide
- Animated progress bars as proficiency indicators
- Smooth animation on scroll into view

## 5. Experience Section
- Vertical timeline layout
- Company name, role, duration, and bullet achievements
- 3-4 placeholder entries
- Alternating or left-aligned timeline cards

## 6. Contact Section with Working Email
- Elegant form: Name, Email, Message fields
- **Lovable Cloud edge function** to send real emails via Resend API
- Success/error toast notifications
- Social icon links (LinkedIn, GitHub, Twitter/X, Email)
- Resume download button (placeholder PDF link)

## 7. Design System & Theme
- **Colors**: Deep Indigo primary, Teal accent, cool grays, off-white/charcoal backgrounds
- **Dark/Light mode** with toggle button and auto-detect
- Glassmorphism card accents, soft shadows
- 8px spacing grid, rounded corners (8-16px)
- WCAG AA contrast compliance

## 8. Navigation & Interactions
- Sticky top navbar with smooth scroll to sections
- Mobile: hamburger menu with slide-in drawer
- Bottom-anchored mobile nav option
- Micro-interactions: button hover glow, card lift, animated skill bars, section fade-in transitions
- Lazy loading for project images
